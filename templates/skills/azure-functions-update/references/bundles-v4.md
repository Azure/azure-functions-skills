# Extension Bundles v4

Use this reference to update an extension bundle from v1, v2, or v3 to v4.

- Start with [extension bundle updates](https://learn.microsoft.com/en-us/azure/azure-functions/extension-bundles#upgrade-extension-bundles).
- To compare included extensions, use the [bundle version table](https://learn.microsoft.com/en-us/azure/azure-functions/extension-bundles#bundle-versions) and [official releases](https://github.com/Azure/azure-functions-extension-bundles/releases).

Check breaking changes only for extensions used by the app. A bundle version change alone does not establish compatibility. Compiled .NET projects use explicit extension packages instead of bundles.
