# Functions Host v3 to v4

Use this reference when the app uses Functions host v3.

- Start with the [official migration guide](https://learn.microsoft.com/en-us/azure/azure-functions/migrate-version-3-version-4). Select the app's language.
- To select a supported target language, use [supported languages](https://learn.microsoft.com/en-us/azure/azure-functions/supported-languages).
- For extension compatibility, use [minimum extension versions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-versions#minimum-extension-versions).

The host migration guide also covers C# model changes. Do not repeat that migration through a second workflow.
