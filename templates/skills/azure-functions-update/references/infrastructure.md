# Infrastructure Configuration

Use this reference only if an existing Bicep file, ARM template, or deployment script must change for the selected migration.

- Start with [Functions infrastructure configuration](https://learn.microsoft.com/en-us/azure/azure-functions/functions-infrastructure-as-code). Select the existing hosting plan.
- For runtime settings, use [language version updates](https://learn.microsoft.com/en-us/azure/azure-functions/update-language-versions).
- If the deployment method needs a change, use [deployment technologies](https://learn.microsoft.com/en-us/azure/azure-functions/functions-deployment-technologies).

These are configuration references, not a general migration guide. Keep resource identity and unrelated settings. A local file update does not authorize resource creation, replacement, or deployment.
