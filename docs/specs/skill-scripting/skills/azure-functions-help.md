## 概要と目的

このスキルは変更しません。

## 理由

- 行うのは、ユーザーの目的を聞き、エージェントが持つスキル一覧から合うものを選ぶことだけです。コマンドを実行しません。
- スキル一覧は、エージェントの実行環境の中にあります。スクリプトからは見えません。
- SKILL.md は30行で、すでに最小です。

## 関連する変更

他のスキルで、スクリプトの `next.skill` が次のスキルの候補を返すようになります。
help の選び方と食い違わないよう、`next.skill` の値は、各 SKILL.md の「Next steps」と同じものに限ります。
